# স্টাডি হাব

হোমওয়ার্ক, ক্লাসওয়ার্ক আর নোট শেয়ার করার জন্য একটা সাধারণ, স্ট্যাটিক ওয়েবসাইট। কোনো ব্যাকএন্ড বা ডাটাবেস নেই — শুধু **টেক্সট ফাইলে লিখলেই** পোস্ট সাইটে চলে আসে।

## ফাইল স্ট্রাকচার

```
index.html        মূল পেজ
style.css         ডিজাইন
script.js         বিষয়ের তালিকা + টেক্সট ফাইল পার্স করার লজিক
data/
  বাংলা-১.txt                              প্রতিটা বিষয়ের ফাইলের নাম বিষয়ের নামের মতোই
  ইংরেজি-১.txt
  কম্পিউটার অফিস অ্যাপ্লিকেশন-১.txt
  ব্যবসায় গণিত ও পরিসংখ্যান.txt
  হিসাববিজ্ঞান নীতি ও প্রয়োগ-১.txt
  অর্থনীতি ও বাণিজ্যিক ভূগোল.txt
  ব্যবসায় সংগঠন ও ব্যবস্থাপনা-১.txt
  মার্কেটিং নীতি ও প্রয়োগ-১.txt
  ডিজিটাল টেকনোলজি ইন বিজনেস-১.txt
  হিউম্যান রিসোর্স ম্যানেজমেন্ট-১.txt
  teachers.txt               স্যার/ম্যাডামদের নম্বর
  social.txt                 গ্রুপ/পেজের লিংক
```

প্রতিটা বিষয়ের ফাইলের নাম হুবহু সেই বিষয়ের নামের মতো — নতুন করে কিছু মনে রাখতে হবে না, যে বিষয়ের পোস্ট দিতে চাও সেই নামের `.txt` ফাইলটাই খুঁজে নাও।

## নতুন পোস্ট যোগ করা

সংশ্লিষ্ট বিষয়ের `.txt` ফাইল খুলে **ফাইলের একদম উপরে** একটা নতুন ব্লক বসাও (নতুন পোস্ট সবচেয়ে আগে দেখাবে)। প্রতিটা পোস্ট একটা লাইনে শুধু `-` দিয়ে আগে-পরে ঘেরা থাকে — আগের পোস্টগুলোর মতোই পদ্ধতি:

```
-
DATE: ১৫ জানুয়ারি ২০২৬
এখানে হোমওয়ার্ক বা নোটের লেখা — একাধিক লাইন লেখা যায়।
IMG: https://.../photo1.jpg
IMG: https://.../photo2.jpg
-
DATE: ১৪ জানুয়ারি ২০২৬
শুধু লেখা পোস্ট, কোনো মিডিয়া ছাড়াই।
-
```

দুইটা পোস্টের মাঝে একটা `-` লাইনই যথেষ্ট (উপর ও নিচ মিলিয়ে একটাই থাকলেও চলবে) — চাইলে প্রতি পোস্টের ঠিক আগে ও পরে আলাদা করে `-` লিখলেও কোনো সমস্যা নেই, পার্সার দুই রকমই বোঝে।

### সাপোর্টেড ট্যাগ (প্রতিটা আলাদা লাইনে)

| ট্যাগ | কী করে |
|---|---|
| `DATE: ...` | পোস্টের তারিখ |
| `IMG: url` | একটা ছবি — একাধিকবার লিখলে ফটো গ্যালারি হয়ে যাবে |
| `VID: url` | একটা ভিডিও — একাধিকবার লিখলে ভিডিও গ্যালারি হয়ে যাবে |
| `AUD: url` | অডিও ক্লিপ — ক্লিক করলে প্লেয়ার খুলবে |
| `DRIVE: url (নাম)` | গুগল ড্রাইভ ফাইলের বাটন |
| `LINK: url (নাম)` | যেকোনো লিংকের বাটন |

- ট্যাগ ছাড়া যেকোনো লাইন সাধারণ লেখা হিসেবে দেখাবে।
- `#` দিয়ে শুরু লাইন কমেন্ট — সাইটে দেখাবে না।
- ছবি, ভিডিও, অডিও, লেখা — যেকোনো কম্বিনেশনে একই পোস্টে দেওয়া যায়। শুধু লেখা, শুধু একটা ছবি, একাধিক ছবি, শুধু ভিডিও, একাধিক ভিডিও, শুধু অডিও — সবই চলবে।
- মিডিয়া ফাইল কোথাও হোস্ট করা থাকতে হবে (যেমন GitHub রিপোর নিজের ফোল্ডারে আপলোড করে `raw.githubusercontent.com` লিংক ব্যবহার করা)।

## নতুন বিষয় যোগ করা

`script.js`-এ `SUBJECTS` লিস্টে একটা নতুন লাইন যোগ করো — শুধু `name` (বিষয়ের নাম), `tab` (gold/teal/rust এর যেকোনো একটা রঙ) আর `icon` দিলেই হবে, ফাইলের পাথ নিজে থেকেই বিষয়ের নাম থেকে তৈরি হয়ে যায়। তারপর `data/` ফোল্ডারে ঠিক সেই নামে (বিষয়ের নাম + `.txt`) একটা ফাইল বানাও। `icon` হিসেবে script.js-এর `ICONS` অবজেক্টে থাকা যেকোনো একটা নাম দাও (book, language, computer, calculator, coins, globe, briefcase, megaphone, chip, users), অথবা নতুন আইকন যোগ করো।


## দেখার জন্য (লোকালি)

সরাসরি `index.html` ডাবল-ক্লিক করলে ব্রাউজার টেক্সট ফাইল লোড করতে দেবে না (CORS)। তাই এই ফোল্ডারে টার্মিনাল খুলে:

```
python3 -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খোলো।

## GitHub Pages-এ পাবলিশ করা

1. একটা নতুন GitHub রিপো বানাও (যেমন `study-hub`)।
2. এই সব ফাইল ও ফোল্ডার আপলোড করো।
3. রিপোর Settings → Pages-এ গিয়ে branch `main`, folder `/root` সিলেক্ট করে Save করো।
4. কিছুক্ষণ পর `https://<username>.github.io/study-hub/` লিংকে সাইট লাইভ হয়ে যাবে।
5. এরপর যেকোনো সময় শুধু `.txt` ফাইল এডিট করে কমিট করলেই সাইটে নতুন পোস্ট চলে আসবে — কোনো কোড ছোঁয়া লাগবে না।
